# Tesla Stock Price Prediction

## Objective

Predict Tesla stock prices using:

- SimpleRNN
- LSTM

For:

- 1 Day Prediction
- 5 Day Prediction
- 10 Day Prediction

## Technologies

- Python
- TensorFlow
- Streamlit
- Scikit-Learn
- Pandas
- Matplotlib

python src/train_models.py

## Run Streamlit

streamlit run app.py
